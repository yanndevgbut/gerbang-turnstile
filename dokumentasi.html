Dokumentasi API

Kirim tugas, tunggu hasil, gunakan token. Semua contoh di bawah memakai data mock dan kunci contoh.

Mulai cepat

Buat tugas dengan sitekey dan url halaman, lalu polling hingga status ready.

# buat tugas
curl -X POST https://api.gerbang.example/v1/createTask \
  -H "Authorization: Bearer gb_live_XXXX" \
  -d '{"type":"turnstile","sitekey":"0x4AAAA...","url":"https://contoh.id"}'
const res = await fetch("https://api.gerbang.example/v1/createTask", {
  method: "POST",
  headers: { Authorization: "Bearer gb_live_XXXX" },
  body: JSON.stringify({ type: "turnstile", sitekey: "0x4AAAA...", url: "https://contoh.id" })
});
import requests
r = requests.post("https://api.gerbang.example/v1/createTask",
  headers={"Authorization": "Bearer gb_live_XXXX"},
  json={"type": "turnstile", "sitekey": "0x4AAAA...", "url": "https://contoh.id"})

Autentikasi

Sertakan kunci API pada header Authorization: Bearer <kunci>. Kunci uji berawalan gb_test_ dan mengembalikan token mock.
